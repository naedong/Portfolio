# Security policy

## Supported version

Security updates are applied to the latest version on the `main` branch and the public GitHub Pages deployment.

## Reporting a vulnerability

Please report a suspected vulnerability privately by email to `gim21041@gmail.com`. Include the affected page, a short reproduction, and the potential impact. Please do not publish exploit details before a fix is available.

This portfolio is a static site: it does not accept account credentials, payments, or server-side form submissions. External project and contact links are clearly identified before navigation.
